# Lista de tarefas em Python

Projeto em Python para criar uma lista de tarefas, com a possobilidade de inserir, remover
 e marcar tarefas como feitas, tambem podendo exportar essa lista em um arquivo externo.

## Funcionalidades

- Registrar tarrefas
- Consultar tarefas
- Marcar tarefas como realizadas
- Remover tarefas da lista
- Exportar tarefas em arquivo texto

## Tecnologias

- Python

## Como executar

```bash
python Lista_de_tarefas.py
